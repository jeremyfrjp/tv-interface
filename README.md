# Hotel TV Interface

A custom-built, lightweight TV interface designed for hotel room displays. This project was created to run on Android TVs using a local server environment (e.g., Apache). It offers a clear and simple user experience optimized for large screens and remote navigation.

## 🖥️ Features

- Clean and modern UI tailored for hotel guest needs
- Optimized for 43–65 inch vertical screen display
- Designed to run fully offline via local intranet
- Simple HTML/CSS/JS architecture for fast loading
- Scalable layout (adapts to different screen sizes without complex responsiveness)
- Easy to update or customize with basic HTML knowledge

## 🚫 Note on Privacy

The public version of this project has sensitive elements (like Wi-Fi QR code and internal videos) removed for security reasons. These can be added back manually in your local setup if needed.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## 🔧 Setup Instructions

1. Clone or download the repository.
2. Place the files in your local web server directory (e.g., `/var/www/html` for Apache).
3. Access the interface from your TV's browser using the local IP or intranet URL.
